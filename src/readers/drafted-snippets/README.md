# drafted snippets

Sett's own scripts for saving chats, as written (Q5). Each one is the
source a default reader in `src/readers/` is fitted from; the snippet stays
here unchanged so the reader can be compared with it. This directory is not
packaged into the extension (`web-ext-config.mjs`) and not formatted by
Biome.

| Snippet | Reader | Webapp |
| --- | --- | --- |
| `google-ai-mode.turndown.js` | `../google-ai-mode.js` | Google Search, AI Mode |
| `github-copilot.turndown.js` | `../github-copilot.js` | GitHub Copilot (immersive chat) |
