## What it asks

- Each artifact (an image, a file, a document or code pane, a canvas) saved beside its chat.
- The chat's Markdown links it where it was born: in that message, a relative link
  (`artifacts/<chat>/<name>`), so the Markdown, the zip and the viewer all show it.
- The unified format grows: a turn's `attachments` (name, type, the path, where it came from)
  - a new format version, `save-my-chat/1` (format.md: changed only with a bump).
- Fetching a file is a network request of the extension: the webapp's own address, the user's
  session, as the page itself does - but rule 4 says it is a question for Sett first. A file
  the page already holds (a blob, an image drawn) needs no request.
- A library and zip that hold files, not only text; the explorer's git sees them too.
