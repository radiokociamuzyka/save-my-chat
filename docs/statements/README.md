# Statements

The project's formal texts, kept here so each has one source: the public site reads them
as they are on `master`, raw from the repository (Sett, issue #7), and Read the Docs shows
them with the manual.

- [privacy.md](privacy.md): the privacy statement, as AMO's listing links it.
- [listing.md](listing.md): the store listing on addons.mozilla.org - its name, summary,
  description, categories and links, filled in by hand on AMO (Sett's).

A change here is a change of what the project promises: it goes to Sett first, and the
date at the top of the statement changes with it.
